3. Project Overview & Problem Statement

Problem Solved: Every winter across Northern India (Punjab, Haryana, Delhi-NCR), seasonal crop residue burning combined with atmospheric temperature inversion traps toxic particulate matter (PM2.5/PM10) near ground level. Existing weather applications merely display an abstract numerical AQI (e.g., 250) and broadcast generic precautions.

The Solution: AirScape translates abstract pollution metrics into a live CSS-driven atmospheric visual scene (altering sky gradients, solar attenuation blur, and haze density in real time). It features an exposure algorithm calculating an Effective Personal AQI customized for age, outdoor hours, and respiratory sensitivity, a 24-hour predictive activity planner, and an interactive Drag and Drop city comparison tool.

4. Technologies Used
  • Semantic HTML5: Document hierarchy, accessible forms (sliders, radio fieldsets), SVG skyline horizon, EPA standard table, embedded wind map iframe, and audio element.
  • CSS3 Design System: CSS Variables (EPA AQI palettes), Flexbox navigation, responsive CSS Grid, hardware-accelerated transitions (0.8s ease), and keyframe pulse animations.
  • Vanilla JavaScript (ES6): Asynchronous API calls, DOM manipulation, functional programming (.reduce, .filter, .map), regex validation, and lexical closures.
  • Browser APIs: Fetch API (Open-Meteo REST endpoints), Geolocation API (GPS lookup), HTML5 Drag & Drop API, and dual-tier Web Storage (localStorage & sessionStorage).
