About AirScape

Solving the winter air crisis communication gap through interactive web technology.

The Real-World Problem

Every winter across Northern India (Punjab, Haryana, Delhi-NCR), seasonal stubble burning, low wind speeds, and temperature inversions trap hazardous particulate matter near the ground.

Traditional weather applications simply display an arbitrary AQI number (e.g. 240) and give identical generic warnings to all users. A healthy 20-year-old athlete and an asthmatic child need completely different precautions.

AirScape transforms numbers into lived experience: rendering the sky's actual visual density and adjusting health advice based on age, respiratory sensitivity, and outdoor exposure time.

How It Works

  1. Live Open-Meteo Integration: Fetches hourly US AQI, PM2.5, and PM10 metrics without proprietary API keys.
  2. CSS-Driven Atmospheric Sky Simulator: Smoothly transitions sky gradients, sun blur, and haze opacity using CSS variables.
  3. Personalized Exposure Algorithm: Computes Effective AQI scaling by +35% for respiratory conditions and +20% for pediatric/elderly age groups.
  4. Offline-First Resilience: Gracefully falls back to cached data for 10 Indian cities if the network is disconnected.
  5. Persistent User Preferences: Leverages LocalStorage and SessionStorage to remember your saved cities and profile settings.
